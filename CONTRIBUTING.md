# Contributing

## Commit messages

- Use sentence case and present tense
- Start with an imperative verb, not a type prefix (e.g., "Add" not "feat: add")
- Keep messages concise and focused on intent, avoiding file names or code excerpts
- For non-functional changes, include keywords like `docs` or `CI`
- Optionally, use a `for ...` suffix to clarify intent when it adds value

### Example

```
Add contribution guidelines and reference them in docs
```

## Code style

Follow the conventions present in the codebase. Format Nix files with `nixfmt`.
